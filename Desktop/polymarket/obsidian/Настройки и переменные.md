# Настройки и переменные

Все настройки проекта задаются через переменные окружения в файле `.env` и конфигурационные файлы.

## Файлы конфигурации

| Файл | Назначение |
|------|------------|
| `.env` | Переменные окружения для `copy_trader.py` |
| `config.py` | Конфигурация бота и базы данных |
| `wallets.txt` | Список кошельков для мониторинга |
| `seen_trade_ids.json` | История обработанных сделок |
| `take_profit_state.json` | Состояние take-profit ордеров |

## `.env` — основные переменные для `copy_trader.py`

| Переменная | Значение по умолчанию | Описание |
|------------|------------------------|----------|
| `POLY_PRIVATE_KEY` | *обязательно* | Приватный ключ Polymarket (Polygon) |
| `POLY_API_KEY` | *обязательно* | API ключ CLOB |
| `POLY_SECRET` | *обязательно* | Секрет CLOB |
| `POLY_PASSPHRASE` | *обязательно* | Пароль CLOB |

| `COPY_NOTIONAL_USD` | `1.05` | Сумма в USDC.e для каждой сделки |
| `MIN_ORDER_SIZE` | `5.5` | Минимальный размер ордера в активах |
| `MIN_SELL_ORDER_SIZE` | `0` | Минимальный размер SELL ордера |
| `MIN_ORDER_NOTIONAL` | `1` | Минимальная стоимость ордера в USD |
| `BALANCE_BUFFER_USD` | `0.50` | Резерв для предотвращения ошибок баланса |

| `FETCH_RETRIES` | `1` | Количество попыток запроса |

| `HEARTBEAT_SEC` | `60` | Интервал отправки heartbeat в health.json |
| `SEEN_TRADES_FILE` | `"seen_trade_ids.json"` | Путь к файлу истории сделок |
| `SEEN_TRADES_MAX` | `2000` | Макс. количество сохранённых ID |
| `LOCK_FILE` | `".copy_trader.lock"` | Путь к lock-файлу |
| `HEALTH_FILE` | `"copy_trader.health.json"` | Путь к файлу статуса |
| `HTTP_BACKOFF_SEC` | `0.75` | Задержка между retry-запросами |
| `TAKE_PROFIT_ENABLE` | `1` | Включить take-profit |
| `TAKE_PROFIT_TRIGGER_PCT` | `0.20` | Порог роста для активации (20%) |
| `TAKE_PROFIT_LOCK_PCT` | `0.10` | Целевая прибыль для лимит-ордера (10%) |

| `LOW_ENTRY_MAX_AVG` | `0.30` | Макс. цена входа (30¢) |

## `config.py` — настройки бота

```python
BOT_TOKEN = os.getenv("BOT_TOKEN", "")
ADMIN_CHAT_ID = int(os.getenv("ADMIN_CHAT_ID", "0"))
DATABASE_PATH = os.getenv("DATABASE_PATH", "polymarket.db")
PMTRACK_BOT_USERNAME = "PMTrackBot"
```

## `wallets.txt`

Файл со списком кошельков, которые нужно мониторить. Один адрес на строку:

```txt
0x1234567890123456789012345678901234567890
0xabcdef0123456789abcdef0123456789abcdef01
```

> **Важно:** Все адреса должны начинаться с `0x` и быть в нижнем регистре.

## `seen_trade_ids.json`

JSON-массив строк с ID обработанных сделок:

```json
["123456", "789012", "345678"]
```

## `take_profit_state.json`

JSON-объект с состоянием take-profit для каждого токена:

```json
{
  "123456": {
    "tp_placed": true,
    "tp_price": 0.85,
    "entry_avg": 0.72,
    "placed_at": "2026-04-18T10:30:00Z",
    "tp_order_id": "ord_abc123"
  }
}
```

## Рекомендации по настройке

- Никогда не коммитите `.env` в Git — добавьте его в `.gitignore`
- Используйте `POLY_FUNDER_ADDRESS` — это необходимо для корректной работы take-profit
- Начните с `TAKE_PROFIT_DRY_RUN=1` и `PROFIT_TAKE_DRY_RUN=1` для тестирования
- Установите `SELL_ONLY_IN_PROFIT=1` и `COPY_SELLS=1` для агрессивной стратегии
- Используйте `ALLOWED_MARKET_KEYWORDS` для фильтрации только интересных рынков (например, `"ETH, BTC, SOL"`)
- Для тестов установите `POLL_INTERVAL_SEC=5` и `ORDER_COOLDOWN_SEC=10`

> **Важно:** Все настройки должны быть оттестированы на демо-среде или с малым капиталом перед запуском в продакшн.
