# Аналитика и отчёты

Аналитика проекта реализована в `analyzer.py` и доступна через Telegram-бота через команды `/stats`, `/top`, `/wallet`, `/report`.

## Функции аналитики

### 1. `format_global_report()`

Генерирует глобальный отчёт:

- Общее количество сделок
- Количество уникальных кошельков
- Общий объём торгов (BUY + SELL)
- Объёмы BUY и SELL
- Топ-рынок по количеству сделок

**Пример вывода:**

```
📊 *Общая статистика*

📈 Всего сделок: 1,247
👥 Уникальных кошельков: 89
💸 Общий объём: $14,230.50
🟢 BUY объём: $8,920.10
🔴 SELL объём: $5,310.40
🏆 Топ-рынок: ETH vs USD (321 сделка)
```

### 2. `format_top_report(limit=10)`

Топ-трейдеры по прибыли (realized_pnl):

- Сортирует кошельки по `realized_pnl DESC`
- Показывает сумму прибыли, общее число сделок
- Поддерживает параметр `limit`

**Пример вывода:**

```
🏆 *Топ-5 трейдеров по прибыли*

1. 0x89ab...cdef — +$1,420.50 (32 трейда)
2. 0x1234...5678 — +$980.20 (21 трейда)
3. 0x5555...aaaa — +$760.10 (45 трейда)
4. 0x6666...bbbb — +$610.80 (18 трейда)
5. 0x7777...cccc — +$520.00 (27 трейда)
```

### 3. `format_wallet_report(wallet)`

Детализированный анализ одного кошелька:

- История сделок (последние 10)
- Общие показатели: количество BUY/SELL, объёмы, PnL
- Процентное соотношение BUY/SELL
- Время первой и последней сделки

**Пример вывода:**

```
👤 *Анализ кошелька: 0x123...abc*

📊 Всего сделок: 42
🟢 BUY: 31 (73.8%) — $4,210.50
🔴 SELL: 11 (26.2%) — $2,105.30
💰 Прибыль (PnL): +$2,105.20

📅 Первый сигнал: 2026-04-10
📅 Последний сигнал: 2026-04-18

📋 Последние 5 сделок:
🟢 BUY ETH 1.5@0.82 | $1.23 — 2026-04-18
🔴 SELL ETH 1.5@0.91 | $1.37 — 2026-04-17
🟢 BUY BTC 0.2@0.68 | $0.14 — 2026-04-16
🟢 BUY ETH 2.0@0.79 | $1.58 — 2026-04-15
🔴 SELL ETH 2.0@0.85 | $1.70 — 2026-04-14
```

## Форматирование

- Все отчёты выводятся в формате **Markdown для Telegram**
- Используются эмодзи: 📊, 👤, 📈, 🟢, 🔴, 🏆, 💰, 📅
- Числа форматируются с тысячными разделителями (`$1,230.50`)
- Даты — в формате `YYYY-MM-DD`

## Техническая реализация

Все отчёты строятся на данных из базы `database.py`:

- `get_global_stats()` → `/stats`, `/report`
- `get_top_wallets()` → `/top`
- `get_wallet_trades()` и `get_wallet_stats()` → `/wallet`

Нет промежуточных кэшей — все запросы выполняются в реальном времени.

## Рекомендации

- Используйте `/report` для ежедневного обзора
- Проверяйте `/top` для выявления новых инсайдеров
- Анализируйте `/wallet` перед копированием неизвестных кошельков
- Всегда сверяйте `realized_pnl` с `buy_volume` и `sell_volume`

> **Важно:** Аналитика — это ваш инструмент для принятия решений. Не полагайтесь только на прибыль — анализируйте частоту, объёмы, рынки и динамику.
