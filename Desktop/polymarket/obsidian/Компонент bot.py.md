# Компонент: bot.py

Telegram-бот для приёма, анализа и отображения сигналов от @PMTrackBot.

## Назначение

Принимает текстовые сообщения от @PMTrackBot (например, "🟢 BUY ETH 2.34@0.78"), сохраняет их в базу данных и предоставляет команды для анализа истории трейдинга.

## Команды

| Команда | Параметры | Описание |
|---------|-----------|----------|
| `/start` | — | Приветствие и список команд |
| `/help` | — | Тот же вывод, что и `/start` |
| `/stats` | — | Общая статистика проекта: трейды, кошельки, объём |
| `/top [N]` | N (опц.) | Топ N трейдеров по прибыли (по умолчанию 10) |
| `/wallet <addr>` | адрес кошелька | Подробный анализ кошелька: история, объёмы, PnL |
| `/recent [N]` | N (опц.) | Последние N сделок (по умолчанию 10) |
| `/report` | — | Полный отчёт: статистика + топ-10 |

## Обработка сообщений

Бот парсит сообщения по шаблону:

```
🟢 BUY ETH 2.34@0.78
👤 0x123...abc
📊 Market: XYZ
```

Извлекает:

- `action`: BUY / SELL
- `asset`: ETH, BTC и т.д.
- `price_cents`: цена в центах (0.78 → 78¢)
- `amount_usd`: объём в USD (2.34 * 0.78)
- `wallet`: адрес кошелька
- `market`: название рынка

После парсинга сигнал сохраняется в базу данных через `database.insert_trade()`.

## Авторизация

- Доступ к командам ограничен: если `ADMIN_CHAT_ID` ≠ 0 — только чат с этим ID
- Если `ADMIN_CHAT_ID=0` — доступ разрешён всем
- Логи всех входящих сообщений записываются в `bot.py.log`

## Интеграция с базой данных

Использует `database.py` для:

- Сохранения новых сделок в таблицу `trades`
- Обновления статистики кошельков в таблице `wallet_stats`
- Получения данных для отчётов

## Формат отчётов

Отчёты генерируются `analyzer.py` в формате Markdown для Telegram:

Пример `/top 5`:

```
🏆 Топ-5 трейдеров по прибыли:

1. 0x89ab...cdef — +$1420.50 (32 трейда)
2. 0x1234...5678 — +$980.20 (21 трейда)
3. 0x5555...aaaa — +$760.10 (45 трейда)
...
```

## Ограничения

- Поддерживает только форматы от @PMTrackBot
- Не обрабатывает изображения, кнопки или медиа
- Не поддерживает мультиязычность — работает только с английскими/цифровыми обозначениями

## Рекомендации

- Используйте `ADMIN_CHAT_ID` для безопасности
- Не включайте бота в публичные чаты
- Всегда проверяйте, что бот получает только сообщения от @PMTrackBot
- Регулярно проверяйте `polymarket.db` — это ваша основная база данных

> **Важно:** Бот не участвует в торговле — он только фиксирует сигналы и предоставляет аналитику. Все действия по копированию выполняет `copy_trader.py`.
