# Компонент: copy_trader.py

Автоматический копировщик сделок с кошельков инсайдеров на Polymarket через CLOB API.

## Основные функции

- Мониторинг кошельков из `wallets.txt`
- Копирование BUY/SELL сделок с сохранением истории в `seen_trade_ids.json`
- Поддержка режимов: `COPY_SELLS`, `SELL_ONLY_IN_PROFIT`, `SHORT_TERM_WALLET`
- Автоматический take-profit: при росте позиции на `TAKE_PROFIT_TRIGGER_PCT` (по умолчанию +20%) ставит лимит-ордер на `TAKE_PROFIT_LOCK_PCT` (+10%)
- Мгновенное закрытие позиции при прибыли ≥ `PROFIT_TAKE_USD` (по умолчанию $30)

## Настройки (из `.env`)

| Параметр | Значение по умолчанию | Описание |
|----------|------------------------|----------|
| `COPY_NOTIONAL_USD` | 1.05 | Размер сделки в USDC.e |
| `MIN_ORDER_SIZE` | 5.5 | Минимальный размер ордера в активах |
| `POLL_INTERVAL_SEC` | 30 | Интервал опроса кошельков |
| `TAKE_PROFIT_ENABLE` | 1 | Включить take-profit |
| `TAKE_PROFIT_TRIGGER_PCT` | 0.20 | Порог роста для активации (+20%) |
| `TAKE_PROFIT_LOCK_PCT` | 0.10 | Целевая прибыль для лимит-ордера (+10%) |
| `PROFIT_TAKE_ENABLE` | 1 | Включить мгновенное закрытие прибыли |
| `PROFIT_TAKE_USD` | 30 | Порог закрытия в USD |
| `COPY_SELLS` | 1 | Копировать SELL-сделки |
| `SELL_ONLY_IN_PROFIT` | 1 | Копировать SELL только в прибыли |
| `SHORT_TERM_WALLET` | (пусто) | Кошелёк, у которого разрешены краткосрочные сделки |
| `SHORT_TERM_MIN_PRICE` | 0.05 | Минимальная цена для краткосрочных (`0.05` = 5¢) |
| `SHORT_TERM_MAX_PRICE` | 0.20 | Максимальная цена для краткосрочных (`0.20` = 20¢) |

## Алгоритм работы

1. Запускается один экземпляр через `fcntl.lock`
2. Загружает список кошельков из `wallets.txt`
3. Загружает историю сделок из `seen_trade_ids.json`
4. Для каждого кошелька:
   - Получает последние сделки через Polymarket API
   - Проверяет, не обработан ли `trade_id`
   - Проверяет ключевые слова рынка (`ALLOWED_MARKET_KEYWORDS`)
   - Проверяет, не является ли рынок краткосрочным (если не исключение)
   - Формирует ордер на CLOB API
   - Сохраняет `trade_id` в историю
5. Периодически (каждые `TAKE_PROFIT_CHECK_SEC`):
   - Проверяет свои позиции через `fetch_my_positions()`
   - Если рост > `TAKE_PROFIT_TRIGGER_PCT` → ставит лимит-ордер на `TAKE_PROFIT_LOCK_PCT`
6. Периодически (каждые `PROFIT_TAKE_CHECK_SEC`):
   - Закрывает позиции, если прибыль ≥ `PROFIT_TAKE_USD` или в диапазоне `LOW_ENTRY_TAKE_PROFIT_USD`

## Ошибки и обработка

- Ошибки баланса (`not enough balance / allowance`) — обрабатываются с разбором
- Ошибки сети — повторные запросы с экспоненциальной задержкой
- Повторные ордера — блокируются через `recent_order_times`
- Пропуск закрытия — если ордер уже живой (`has_live_order`)

## Файлы состояния

- `seen_trade_ids.json` — массив ID обработанных сделок
- `take_profit_state.json` — состояние take-profit для каждого токена
- `copy_trader.health.json` — статус, время, PID, баланс
- `.copy_trader.lock` — lock-файл для предотвращения дублирования
- `copy_trader.supervisor.log` — логи работы через `supervisor`

## Рекомендации

- Используйте `POLY_FUNDER_ADDRESS` для управления позициями
- Настройте `RESERVE_CASH_USD` для резервирования средств на комиссии
- Не копируйте сделки с неизвестных кошельков — используйте `WATCH_ONLY_WALLET`
- Всегда проверяйте `copy_trader.health.json` перед запуском

> **Важно:** Этот компонент работает в режиме "независимого трейдера" и не требует постоянного управления. Всё управление — через конфиг и файлы состояния.
