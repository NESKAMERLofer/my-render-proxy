# Запуск и эксплуатация

Инструкции по развертыванию, запуску и поддержке системы Polymarket Copier.

## Предварительные требования

- Python 3.10+ (рекомендуется 3.13)
- Установленный `pip` и `venv`
- Доступ к Polymarket CLOB API (ключей)
- Telegram-бот с токеном (@BotFather)
- Права на запись в папку проекта
- macOS или Linux (на Windows возможны проблемы с `fcntl`)

## Шаг 1: Клонирование и настройка

```bash
cd /Users/grigorijtoropov/Desktop/polymarket
python -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

## Шаг 2: Создание конфигурационных файлов

### 1. `.env` — ключи Polymarket

Создайте файл `.env` в корне проекта:

```env
POLY_PRIVATE_KEY=your_private_key_here
POLY_API_KEY=your_api_key_here
POLY_SECRET=your_secret_here
POLY_PASSPHRASE=your_passphrase_here
POLY_FUNDER_ADDRESS=0xYourFunderAddressHere
POLY_SIGNATURE_TYPE=0

COPY_NOTIONAL_USD=1.05
MIN_ORDER_SIZE=5.5
POLL_INTERVAL_SEC=30
TAKE_PROFIT_ENABLE=1
TAKE_PROFIT_TRIGGER_PCT=0.20
TAKE_PROFIT_LOCK_PCT=0.10
PROFIT_TAKE_ENABLE=1
PROFIT_TAKE_USD=30
COPY_SELLS=1
SELL_ONLY_IN_PROFIT=1

BOT_TOKEN=your_telegram_bot_token_here
ADMIN_CHAT_ID=123456789
DATABASE_PATH=polymarket.db
```

> **Важно:** Не коммитите `.env` в Git. Добавьте его в `.gitignore`.

### 2. `wallets.txt`

Создайте файл `wallets.txt` со списком кошельков:

```txt
0x1234567890123456789012345678901234567890
0xabcdef0123456789abcdef0123456789abcdef01
0x9876543210987654321098765432109876543210
```

### 3. `config.py`

Изменения в `config.py` не требуются — он читает переменные из `.env` автоматически.

## Шаг 3: Запуск

### Запуск бота (в отдельном терминале)

```bash
python bot.py
```

Бот будет ждать сигналы от @PMTrackBot в Telegram.

### Запуск copy_trader (в отдельном терминале)

```bash
python copy_trader.py
```

Система начнёт мониторить кошельки и копировать сделки.

## Шаг 4: Автоматический запуск (на macOS)

Используйте `launchd` для автозапуска при перезагрузке:

```bash
# Скопируйте plist-файл
cp launchd.copy_trader.plist ~/Library/LaunchAgents/

# Загрузите службу
launchctl load ~/Library/LaunchAgents/launchd.copy_trader.plist

# Проверьте статус
launchctl list | grep copy_trader
```

Скрипт `run_copy_trader_forever.sh` обеспечивает перезапуск при падении:

```bash
chmod +x run_copy_trader_forever.sh
./run_copy_trader_forever.sh
```

## Шаг 5: Мониторинг

### Файлы состояния

- `copy_trader.health.json` — статус, PID, баланс, время
- `take_profit_state.json` — состояние ордеров take-profit
- `seen_trade_ids.json` — история обработанных сделок
- `copy_trader.log` — логи работы
- `copy_trader.supervisor.log` — логи supervisor

Проверяйте их регулярно:

```bash
cat copy_trader.health.json | jq .
```

### Telegram-бот

Используйте команды:
- `/stats` — общая статистика
- `/top 5` — топ-5 трейдеров
- `/wallet 0x123...abc` — анализ кошелька
- `/recent 10` — последние 10 сделок
- `/report` — полный отчёт

## Шаг 6: Обновление и обслуживание

### Обновление зависимостей

```bash
pip install --upgrade -r requirements.txt
```

### Обновление кода

```bash

```

### Перезапуск

```bash
# Остановить copy_trader (найти PID и убить)
pkill -f copy_trader.py

# Запустить снова
python copy_trader.py
```

## Рекомендации по эксплуатации

- Не запускайте более одного экземпляра `copy_trader.py` — это приведёт к дублированию ордеров
- Проверяйте `copy_trader.health.json` хотя бы раз в день
- Регулярно делайте бэкап `polymarket.db`
- Проверяйте баланс USDC.e на CLOB — если он падает ниже $10, пополните его
- Используйте `TAKE_PROFIT_DRY_RUN=1` для теста новых настроек
- Не копируйте сделки из кошельков с низкой активностью — фильтруйте через `ALLOWED_MARKET_KEYWORDS`
- Следите за обновлениями Polymarket API — они могут изменить формат ответов

> **Важно:** Этот проект работает в режиме "запустил и забыл", но требует **регулярного мониторинга**. Никогда не запускайте его с крупным капиталом без предварительного тестирования на малых суммах.
